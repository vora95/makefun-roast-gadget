A small program that writes one short text (129 characters) to `/output/entry.txt`: a roast of the wireless earbuds used every day — they die at 7% with no warning, while their case, fully charged, just sits in the pocket holding the power like a grudge.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
